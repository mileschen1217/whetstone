`brief.md` is the accepted contract for this unit of work. Build it in this repo. `checks/` holds one check per criterion; do not edit anything under `checks/`.

When you are done, write `out/verdict.md`: one line per criterion, in the form `AC-n PASS|FAIL|DISPUTED — the evidence`.

Work test-first: for each criterion, run its check and see it fail before you implement it, and where the check is thin add your own test under `tests/` before the code.
