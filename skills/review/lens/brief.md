The subject is a brief.md before it is signed, with its checks and the request or epic it was written from. Two lists; a yes is a finding, nothing else is; the review ends when both are walked, and nothing found is the single word `clean`.

1. Each criterion in the table, three questions:
   - **under** — does the check test less than the Behaviour says: a clause, a boundary value, a case the sentence names and the command never exercises?
   - **over** — does the check assert something no criterion, no `B-n` and no `REQ-n` fixes (a message text, a format, a name the brief left free)?
   - a Behaviour that no command can decide (a target must be reached, a paid run made, a person reads and decides) is `live` and names what decides it and where its evidence is recorded; one decided by a proxy instead is **under**.
2. Each `B-n` under Decisions and each `REQ-n` named in `From`: which criterion goes red when it is ignored? None: **no red AC**.

A finding names the line, the id and the word: `- brief.md:<line> — AC-n under|over — <what>` or `- brief.md:<line> — B-n no red AC — <why nothing goes red>`.
